1. 클라이언트 사이드 내비게이션
=> 전체 페이지를 새로고침하지 않고 사용자가 방문한 페이지를 전환하는 방식입니다.


2. 주요 특징
2-1. 페이지 새로고침 없음
=> 네비게이션은 자바스크립트가 현재 페이지 DOM(Document Object Model)을 조작하여 수행됩니다.

2-2. 빠른 전환
=> 페이지를 새로고침하지 않고 필요한 데이터만 요청하므로 속도가 빠릅니다.

2-3. 라우팅 제어
=> Next.js의 Link 컴포넌트와 같은 클라이언트 사이드 라우팅 도구를 사용하여 내비게이션이 구현됩니다. 

2-4. 히스토리 관리
=> 브라우저의 window.history.pushState와 같은 API를 통해 URL 변경과 네비게이션 기록을 관리합니다.
