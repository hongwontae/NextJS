=> vercel이 개발한 rust 기반 번들러입니다. (Rust 언어로 작성되어 뛰어난 성능과 효율성을 자랑합니다.)

8. Would you like to customize the import alias
=> 파일 경로를 간소화하기 위해 import alias 여부
=> 루트 디렉토리를 기준으로 경로를 설정할 수 있습니다. 
=> jsconfig.json 또는 tsconfig.json 파일에서 paths 옵션을 사용해 Import Alias를 설정합니다.
=> {
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./*"]
    }
  }
}
=> "@/*": @/를 루트 디렉토리로 매핑합니다.
=> "./*": 현재 루트 디렉토리의 모든 파일을 의미합니다.
=> baseUrl: 프로젝트의 기본 경로를 지정합니다. "."는 프로젝트 루트를 의미합니다.
