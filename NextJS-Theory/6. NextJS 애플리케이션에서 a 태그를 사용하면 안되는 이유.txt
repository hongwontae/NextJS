1. a 태그 사용 안하는 이유
1-1. 전체 페이지 리로드 발생
=> 브라우저가 새 HTML 페이지를 요청합니다.
=> 이는 페이지가 리로드되며, 전체 애플리케이션이 초기화됩니다.

1-2. 성능 저하
=> 새 페이지를 로드할 때 서버와 반복적으로 통신하므로 클라이언트 사이드의 
장점(빠른 네비게이션, 캐싱 등)을 활용하지 못합니다.

1-3. 상태 초기화:
=> 현재 유지 중인 상태(State)나 캐싱된 데이터를 잃게 됩니다.


2. Link 컴포넌트
2-1. Link 컴포넌트는 내부적으로 클라이언트 사이드 네비게이션을 사용하여 페이지 전환 속도를 최적화합니다.

2-2. 장점
1. 네비게이션 속도가 빠름.
2. 브라우저 상태(State)가 유지됨.
3. 필요한 경우 사전 로드(Prefetch)를 통해 성능 향상.
