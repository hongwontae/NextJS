1. 병렬 라우트
=> 하나의 화면에 여러 개의 page.js를 렌더링하는 라우트 방법입니다.


2. 사용법
2-1. root 폴더 하나를 생성합니다.
2-2. root 폴더 내부에 layout.js를 생성합니다.
2-3. 폴더 내부에서 화면에서 렌더링하고 싶은 page.js 따라 폴더를 생성합니다.
=> 이 떄 폴더이름은 앞에 @가 붙어야 합니다.

2-4. layout.js는 @ 폴더의 이름을 children props처럼 사용할 수 있습니다.


3. @ 폴더에서 동적 라우트나 일반 라우트를 생성하고 page.js를 추가했을 떄
3-1. 병렬 라우트이기 떄문에 이와 짝을 맞춘 라우트를 인식하지 못하고 404 page로 이동합니다.
3-2. 이를 해결하기 위해서 짝을 맞출 default.js를 추가해야 합니다.
=> 해당 파일의 역할은 병렬 라우트일 떄 반대편이 내부에서 다른 라우트로 가려고 할 떄의 fallback 역할을 합니다.
=> 만약 default.js와 page.js가 일치한다면 page.js를 삭제해도 로직이 똑같습니다.
