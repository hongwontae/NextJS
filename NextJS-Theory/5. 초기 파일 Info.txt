1. jsconfig.json
=> JavaScript 프로젝트의 설정 파일입니다.

1-1. 모듈 경로 관리: 프로젝트의 기본 경로(baseUrl)와 경로 별칭(paths)을 설정합니다. 
이를 통해 상대 경로 대신 간단한 경로를 사용할 수 있습니다.
1-2. 에디터 지원: Visual Studio Code와 같은 IDE에서 자동 완성과 코드 네비게이션을 활성화합니다.


2. next.config.js
=> next.config.js는 Next.js 애플리케이션의 환경 설정을 위한 파일입니다.

2-1. 주요 역할
1. 빌드 설정: 빌드 속도 최적화, 외부 서비스 통합 등.
2. 환경 변수 설정: 공개 및 비공개 환경 변수를 관리.
3. 리다이렉션 및 리라이트: URL을 재구성하거나 리다이렉트 설정.
4. 이미지 최적화 설정: 이미지 도메인 및 형식을 관리.


3. postcss.config.mjs
=>  Next.js에서 PostCSS 설정을 관리하는 파일입니다.

3-1. 주요 역할
1. CSS 확장: Tailwind CSS나 Autoprefixer와 같은 플러그인을 사용하여 CSS를 확장.
2. CSS 최적화: 불필요한 CSS를 제거하거나 브라우저 호환성을 높임.


4. tailwind.config.mjs
=> Tailwind CSS 설정 파일입니다.

4-1. 주요 역할
1. Tailwind CSS의 기본 테마를 확장하거나 덮어쓰기.
2. 프로젝트에 필요한 사용자 정의 스타일 추가.


5. mjs 확장자를 사용하는 이유
=> ES Module (ESM) 표준을 따르기 위함입니다.
=> .mjs는 ES Module 파일임을 명확히 나타내는 확장자입니다.
=> CommonJS(require/module.exports) 대신 ES Module(import/export)을 사용하려면 mjs 확장자를 사용해야 합니다.
