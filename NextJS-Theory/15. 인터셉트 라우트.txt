1. 인터셉트 라우트
=> 페이지에 어떻게 도달하느냐에 따라서 page.js를 가로채는 라우트입니다.
=> ()가로챌 라우트 이름, (.) 같은 레벨, (..) 하나 뒤로, (..)(..) 하나 위로...


2. 인터셉트 라우트 설명
2-1. 동적 경로를 포함하지 않아도 됩니다.
2-2. 클라이언트 사이드 내비게이션으로 이동하면 인터셉트 라우트가 활성화됩니다.
2-3. 새로고침하면 일반 라우트가 활성화됩니다.


* 인터셉트 라우트 핵심
=> (.)name은 라우팅에 포함되지 않은 폴더로 설계되었습니다. 즉, URL 경로에서 무시됩니다.
=> 그러나 라우트 내에 바로 인터셉트 라우트와 일반 라우트(인터셉트 당할 라우트)가 다이렉트로 존재하면?
=> 인터셉트 라우트를 url이 아니라고 일단 인식해야 하는데 그렇지 않아진다.
=> 즉, 일반 라우트 page.js만 활성화 됩니다.

=> 제대로 사용하려면
=> 일반 라우트 내부에 동적 라우트 or 정적 라우트를 생성하고 이를 처리할 page.js를 생성합니다.
=> 그 안에서 인터셉트 라우트와 인터셉트 당할 라우트를 설정합니다.
