1. 서버 컴포넌트
=> 요청이 전달되면 해당 컴포넌트의 JSX를 기반으로 HTML을 생성한 뒤 브라우저에게 전달하는 컴포넌트입니다.

=> 기본적으로 app 디렉토리에 존재하는 모든 컴포넌트는 서버 컴포넌트입니다.
=> 서버 컴포넌트라면 사이드 클라이언트 내비게이션으로 이동한들 서버에서 렌더링되어 HTML이 전달되는 SSR 형태입니다.
=> 즉, Link 컴포넌트를 통해 접근하더러도 서버 컴포넌트의 원칙을 지킵니다.


2. 심화
=> 서버 컴포넌트에 함수가 존재할 떄 해당 함수는 서버에서 실행되어 데이터가 변경되고
이를 기반으로 HTML이 생성되어 클라이언트에게 전달됩니다.
=> catch-all 라우트의 경우 해당 라우트 page.js에 또 다시 접근할 떄 일어나는 과정입니다.
