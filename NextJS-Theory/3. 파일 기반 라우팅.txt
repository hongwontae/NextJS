1. 파일 기반 라우팅
=> 폴더와 파일의 구조를 통해 라우트를 자동으로 생성하는 방식입니다. 

1-1. 작동 방식
1. pages 디렉토리
=> Next.js 프로젝트의 pages 디렉토리 내부의 파일이 URL 경로를 정의합니다.
=> 예를 들어, pages/about.js 파일은 /about URL에 매핑됩니다.

2. 폴더 구조와 중첩 라우팅
=> 디렉토리 내 파일 구조를 통해 중첩 라우팅을 자동으로 구성할 수 있습니다.

3. 동적 라우팅
=> 동적 경로를 만들기 위해 파일 이름을 대괄호([])로 감쌉니다.
=> pages/post/[id].js → /post/:id

4. 캐치올 라우팅
=> 여러 경로를 한 번에 처리하려면 **캐치올(catch-all)**을 사용합니다.
=> 파일 이름 앞에 ...를 붙여 정의합니다.
=> pages/docs/[...slug].js → /docs/
=> /docs/intro, /docs/setup/installation, /docs/setup/config 등 모든 하위 경로를 처리.

5. 404 페이지
=> pages/404.js 파일을 생성하면, 존재하지 않는 URL에 대해 자동으로 404 페이지를 표시합니다.
