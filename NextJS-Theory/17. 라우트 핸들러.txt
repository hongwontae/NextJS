1. 라우트 핸들러
=> Next.js의 파일 기반 라우팅 시스템을 사용하여 서버 측 요청을 처리하는 엔드포인트를 정의하는 새로운 방법입니다.


2. 사용법
=> 폴더 이름은 상관없으나 app 디렉토리 내부에 있어야 합니다.
=> 파일이름은 route.js여야 합니다.
=> api/hello/route.js => /api/hello 엔드포인트를 처리합니다.


3. 라우트 핸들러 정의하기
3-1. 정의
export async function get(request){
    return new Response('...', {
        status : 200
    })
}
=> 함수 이름은 HTTP 메서드 이름으로 정의해야 합니다.
=> 라우트 핸들러는 매개변수에 request 객체(요청 객체)을 받을 수 있습니다.
=> Response : 응답 데이터를 자체적으로 생성하여 보낼 수 있습니다.
