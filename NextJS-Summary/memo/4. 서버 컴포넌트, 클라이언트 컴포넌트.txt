1. 서버 컴포넌트
=> 서버에서 만들어지는 컴포넌트, 즉 클라이언트는 HTML을 받습니다.

1-1. 일반적으로 컴포넌트를 만들면 서버 컴포넌트입니다.

1-2. 서버 컴포넌트는 서버에서 실행되기 떄문에 DB에 직접 접근할 수 있습니다.
=> 또한 컴포넌트 자체가 async function으로 처리되어 내부에서 await를 사용할 수 도 있습니다.


2. 클라이언트 컴포넌트
=> 클라이언트에서 렌더링되는 컴포넌트, 즉 클라이언트는 JavaScript 코드를 받습니다.
=> 파일 최상단에 'use client'를 작성하면 해당 파일은 클라이언트 컴포넌트입니다.
=> event나 useHook을 사용하려면 클라이언트 컴포넌트여야 합니다.


3. 대체로 서버 컴포넌트가 효율이 좋기 때문에 event나 useHook을 사용하여 표현하고 싶다면
작은 부분으로 쪼개서 사용하는 것이 좋습니다.


4. 각 컴포넌트 유의사항
4-1. 렌더링된 이후 함수의 호출의 주체는 클라이언트가 됩니다.
=> event handler
4-2. 'use server' 키워드를 함수 내부에서 실행하면 클라이언트가 간접적으로 트리거만 하게 됩니다.
=> 서버에서 실행을 보장합니다.
4-3. 또한 'use server' 함수는 번들링에 포함되지 않습니다.
=> 서버에서 실행을 보장합니다.
