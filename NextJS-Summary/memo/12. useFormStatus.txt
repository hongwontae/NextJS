1. useFormStatus
1-1. server actions와 폼 제출 시 발생하는 비동기 작업의 상태를 처리하기 위해 사용됩니다.
1-2. useFormStatus는 Server Actions를 사용하는 폼과 연계되어 동작하도록 설계되었습니다. 따라서 Server Action이
없는 환경에서 사용한다면 모든 값(action, data, method, pending)은 기본값으로 동작하거나, 빈 상태로 유지됩니다.

1-2. 반환 값
1. action
=> 현재 실행 중인 서버 액션 함수를 참조합니다.
=> 폼의 action 속성에 연결된 서버 함수입니다.

2. data
=> 서버에서 반환된 데이터를 나타냅니다.
=> 서버 액션이 성공적으로 실행되면, 서버에서 반환된 데이터를 여기에 저장합니다.

3. method
=> 폼이 제출될 때 사용된 HTTP 메서드(GET, POST, PUT, DELETE 등)를 나타냅니다.
=> 일반적으로 폼의 method 속성에서 지정한 값을 따릅니다.

4. pending
=> 서버 액션이 실행 중일 때 true로 설정됩니다.
=> 비동기 작업의 로딩 상태를 추적하는 데 유용합니다.
