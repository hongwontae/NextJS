1. 서버 사이드 렌더링
1-1. 일반 React 애플케이션은 클라리언트 사이드 렌더링입니다.
=> 완전한 HTML을 볼 수 없기 떄문에 검색 엔진 크롤러가 HTML을 파악하지 못하여 SEO의 효율이 떨어집니다.

1-2. NextJS는 서버 사이드 렌더링 기능이 내장되어 있어 요청이 전달되면 페이지를 구축한 뒤 내려보냅니다.
=> 완전한 HTML을 볼 수 있기 떄문에 검색 엔진 효율성이 좋아집니다.


2. 파일 기반 라우팅
=> 페이지에 필요한 라우트와 경로를 폴더로 정의하는 것은 파일 기반 라우팅이라고 합니다.
=> NJ에서 URL이 변경되더라도 백엔드 요청을 막고 React를 가지고 페이지의 여러 컨텐츠를 렌더링합니다.


3. 풀스택
=> NextJS 코드 내에서 NodeJS를 통해 백엔드 코드를 사용하여 백엔드를 구현할 수 있습니다.
