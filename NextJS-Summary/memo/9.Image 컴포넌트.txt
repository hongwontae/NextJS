1. <Image/>
=> 이미지 최적화와 관리를 자동으로 처리해주는 고급 기능을 제공합니다. 


1-1. next/image에서 해당 컴포넌트를 임포트해야 합니다.
=> import Image from 'next/image';
=> src : 이미지의 경로를 지정합니다. (img 태그와는 다르게 이미지 객체 전체를 넣어줍니다.)
=> alt: 이미지의 대체 텍스트(SEO와 접근성 향상).
=> width와 height: 이미지의 크기를 지정합니다.
Next.js는 이 크기를 기준으로 이미지를 최적화하고, 다른 화면 크기에서 올바르게 표시되도록 합니다.


1-2. 자동 최적화
=> 크기 조정, 형식 변환(예: WebP), **지연 로딩(lazy loading)**을 처리할 수 있습니다. 
1. 자동 크기 조절 : 브라우저 크기에 맞게 이미지를 최적화하여 제공하고, 여러 화면 크기에 맞게
 다양한 해상도 이미지를 생성합니다.
2. 형식 변환 : 이미지의 형식도 자동으로 변환할 수 있습니다.
3. 지연 로딩 : 기본적으로 Image 컴포넌트는 지연 로딩을 활성화합니다.
 사용자가 해당 이미지를 화면에 스크롤할 때 로드됩니다.


1-3. 반응형 이미지
=>  반응형 이미지를 손쉽게 다룰 수 있도록 layout 속성을 제공합니다.
1. responsive : 이미지의 크기를 부모 요소에 맞게 자동으로 조정합니다.
2. intrinsic : 이미지의 원래 크기를 기준으로 반응형으로 크기를 조정합니다. (기본 동작)
3. fixed : 고정된 크기(800x600)에 이미지를 렌더링합니다.
4. fill : 이미지가 부모 컨테이너를 꽉 채우도록 확장됩니다.


1-4. 외부 이미지 지원
=> 외부 이미지 도메인도 지원합니다.
=> 외부 이미지를 사용하려면 next.config.js에서 domains 속성을 설정해야 합니다.
=> module.exports = {
  images: {
    domains: ['example.com'],
  },
};
=> src="https://example.com/image.jpg"


1-5. 로딩 전략
=> Image 컴포넌트는 기본적으로 지연 로딩을 활성화합니다.
=> 로딩 전략을 수동으로 설정할 수 있습니다.
=> loading="eager"는 즉시 이미지를 로드하므로, 화면에 이미지를 빨리 표시할 수 있습니다.
=> lazy일 떄는 사진이 화면에 보이지 않는다면, 네트워크 요청없이 대기 상태로 존재하고 
사용자가 스크롤을 내려서 이미지가 가까워지면 그 시점에 네트워크 요청을 통해 이미지를 가져와서 화면에 표시합니다.

1-6. priority
=> 이미지가 페이지의 중요 요소일 경우, 우선 로드할 수 있게 설정합 니다.

1-7. blurDataURL
=> 이미지를 로딩할 때 모자이크 블러 이미지를 설정하여, 로딩 중 사용자에게 부드러운 경험을 제공할 수 있습니다.


2. width과 height을 명시하지 않아도 Image 컴포넌트가 렌더링되는 이유
=> width와 height를 지정하지 않으면, layout="intrinsic" 모드에서 이미지의 원본 크기가 사용됩니다.


3. loading='eager' VS priority
=> 두 개의 속성 모두 이미지가 즉시 로드되는 속성입니다.
=> priority는 브라우저의 프리로드 기능을 사용하여 HTML인 <link rel='preload'> 태그를 생성하여, 
네트워크 우선순위를 높입니다.
=> priority는 Next.JS 전용 속성, 사용자가 보게 되는 가장 중요한 이미지에 사용하는 속성입니다.
