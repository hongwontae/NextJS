1. <Image>
1-1. import Image from 'next/image';
=> <Image src={imageObject}/> -> imageObject는 컴포넌트에서 import한 사진 객체입니다.

1-2. 자동 이미지 최적화
=> 브라우저 상황에 맞게 이미지 포맷을 자동으로 변환합니다.
=> 또한 사용자 디바이스에 맞게 크기 조절된 이미지를 서버가 생성하여 전송합니다.

1-3. 지연로딩
=> 기본적으로 화면에 보일 때까지 이미지 다운로드를 지연합니다.
=> priority는 지연로딩과 반대로 브라우저가 컴포넌트를 만나면 바로 렌더링합니다.

1-4. 반응형 이미지를 지원
=> sizes + fill, width, height 조합으로 다양한 뷰포트 대응할 수 있습니다.

1-5. 이미지 캐싱 + CDN
=> Next.js가 제공하는 mage Optimization API를 통해 서버나 CDN에서 캐싱합니다.
=> loader 커스터마이징도 가능합니다.

1-6. Blur-up placeholder (로딩 시 흐림 효과)
=> 로딩 중 이미지가 흐릿하게 보였다가 선명하게 나옵니다.


2. 주의 사항
2-1. public 폴더의 이미지나 외부 도메인을 사용해야 합니다.
=> 외부 도메인을 사용할 떄는 next.config.js에서 도메인을 명시적으로 허용해야 합니다.
=> module.exports = {
  images: {
    domains: ['res.cloudinary.com'], // 허용할 외부 이미지 도메인
  },
};
=> 그 이후 src에 url을 추가하면 됩니다.


3. Deep Image
3-1. 이미지 조절 기능
=> 브라우저가 요청한 width, height, device DPR(화면 배율) 값을 바탕으로 다양한 해상도의 이미지를 next 서버가 생성합니다.
=> 서버가 브라우저에 <img srcset="" size="..."> 구조로 전달합니다. 이 때 해상도 별로 여러 srcset이 존재합니다.
(브라우저는 뷰포트에 가장 적합한 이미지 사이즈를 선택)

=> Next Image는 반드시 크기 정보가 필요합니다. width과 height을 명시하든가, fill을 사용하여 부모의 size를 가져오든가
=> 그렇지 않으면 렌더링 되지 않습니다.

=> Image Flow
=> 브라우저에서 NextJS 서버로 width과 height, device DPR 값을 보내고 여러 크기-해상도 별로 이미지를 생성
=> 브라우저는 기기나 크기에 맞는 이미지 채택


3-2. fill
=> 이미지를 부모 요소의 크기에 꽉 차게 맞춰서 렌더링하도록 설정하는 기능입니다.
=> width/height 대신에 부모를 기준으로 "비율 고정 + 꽉 채움" 방식
=> 이 떄 부모 요소는 반드시 position : relative를 가져야 합니다.
